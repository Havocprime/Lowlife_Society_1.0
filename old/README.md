# LOWLIFE Society — Backbone

Discord-first RPG infrastructure for LOWLIFE.

## Quickstart

### 1) Requirements
- Python 3.12+
- Discord Bot Token with message intent enabled

### 2) Clone & env
```bash
git clone https://github.com/Havocprime/Lowlife_Society_1.0.git
cd Lowlife_Society_1.0
python -m venv .venv && . .venv/Scripts/activate
pip install -r requirements.txt
